# Comandos do git
Vou deixar aqui em baixo os comando para puxar o projeto para o pc de vcs e os comando de salvar o projeto do github.

## 1-git clone 
aqui vc escreve git clone no terminal de vscode e colocar a url do repositorio. Ent ficaria assim: 
**git clone https://github.com/MoisesSantos1223/Projeto-A2.git.**

## 2-Entrar na pasta do projeto 
**cd Projeto-A2**
### git pull

Ele atualiza o projeto com as alterações enviadas pelos outros integrantes.
## 3-Salva o codigo
**git add .**
Ele serve para preparar o codigo antes de colocar no github
## 4- fazer um comentario/ commit 
**git commit -m"Comentario do codigo que vc fez"**

## 4- para colocar o codigo no github 
**git push**


# Esses comandos são usado dentro do terminal do vscode
